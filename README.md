# Clevora AI

Smart AI Workspace App — Light theme, 8-capability sheet, manual-send voice, status counter.

## Features

- **Light Theme** — Clean white background (not dark)
- **8-Capability Sheet** — Camera, Photos, Files, Web Search, Create Image, Edit Image, Generate Video, Skills
- **Manual-Send Voice** — Voice dictation only fills draft, never auto-sends (safety first)
- **Status Counter** — Ready/Working/Offline with live timer
- **Settings Panel** — 4 themes (Light/Dark/System/Sepia), voice mode, notifications, auto-save
- **Quick Suggestions** — One-tap action chips
- **Task Plan** — Shows steps before executing
- **Responsive** — Mobile-first design

## Technology

- Pure HTML/CSS/JS — no dependencies
- Local-first — all data in browser localStorage
- Privacy-protected — no tracking, no cookies
